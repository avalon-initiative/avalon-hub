# avalon-hub

The Avalon Hub: the web (`apps/hub`, Vue3 + Vite) and desktop/mobile
(`apps/mobile-hub`, Tauri) client apps — identity setup, friends, guilds,
achievements, and guild/friend presence without a game client open.

**Status:** staged placeholder. Currently lives under
`LunarVagabond/avalon-protocol`'s `apps/` directory and will move here once
it's migrated onto the Avalon SDK in place of raw HTTP calls.
